1.Create a virtual environment:
python -m venv venv
.\venv\Scripts\Activate

2. 📦 Install Required Packages
In your PowerShell terminal: pip install flask flask_sqlalchemy requests python-dotenv

Run the Flask app by executing:
python main.py

If everything is set up correctly, you should see the Flask server running with output like this:

* Running on http://127.0.0.1:5000/ (Press CTRL+C to quit)
3. Access the Web Application:

Open your browser and go to the following URL:
http://127.0.0.1:5000/
